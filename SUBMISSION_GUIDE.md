# Submission guide — Project 1 only

Your submission form requires **four HTTPS URLs**. This package prepares the underlying code and documents; it does not create or claim any live URLs for you.

| Form field | What to link | How to obtain it |
|---|---|---|
| 1. GitHub Repository Link | Your new public/accessible GitHub repository for **Product Profitability**, not the shipping-route project | Create repository and upload extracted ZIP contents; copy repository URL `https://github.com/<YOUR_USER>/<YOUR_REPO>` |
| 2. Research paper link | The project research paper, accessible to reviewers | Upload `reports/Nassau_Product_Profitability_Research_Paper.pdf` to Google Drive and share with reviewer-view permission, or give the direct GitHub PDF link *if accepted by your program* |
| 3. Deployed project link | The actual running Product Profitability Streamlit dashboard | Deploy `app.py` to Streamlit Community Cloud and copy the resulting `https://<your-app>.streamlit.app` URL |
| 4. Project Feedback video link | Your own recorded video explaining project experience and learnings | Record yourself narrating your experience, upload to accessible Drive/YouTube, copy the viewable HTTPS link |

**Important:** The form says research paper should be approved/published *if applicable*. This project includes an original research-style report, **not** a peer-reviewed or formally approved publication. Ask the course administrator if approval is mandatory.

## Quick deployment checklist

- [ ] Extract ZIP fully; check that `app.py`, `analytics.py`, `data/`, `requirements.txt` are at repository root.
- [ ] Test locally with `python -m streamlit run app.py` and view charts/filters.
- [ ] Create **separate** GitHub repository from Project 2.
- [ ] Deploy new Streamlit app; verify in a private/incognito browser.
- [ ] Host research PDF with viewable link; test access while logged out.
- [ ] Record feedback video in your own words and host with viewable link.
- [ ] Copy four working `https://` URLs into the form, one per field.

## Keep the two submissions separate

- Project 1: **Product Line Profitability & Margin Performance Analysis** (this package).
- Project 2: **Factory-to-Customer Shipping Route Efficiency Analysis** (earlier route-efficiency package).

The projects can use the same case dataset, but their hypotheses, KPIs, reports and Streamlit code should not be interchanged.
